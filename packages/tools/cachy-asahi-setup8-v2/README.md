# Setup8 0.3.1-1 candidate

This MIT-licensed recipe builds the same ALPM package name as Setup8 0.3.0-1.
Its baseline inputs are copied from the Setup8 recipe at
`6eb7c9df3bbd1c035f305df659132668ced64116`. The recipe pins each input and
applies `fish-quoting.patch` to a private copy of the setup and migration
modules. It verifies both resulting file digests.

Fish interprets consecutive backslashes inside a single-quoted path as escapes.
Setup now quotes such paths for Fish, including paths with apostrophes.
It recognizes exact blocks generated by either recipe. For an affected
existing block, preview with `cachy-asahi-setup activate --components fish`
using the original template and configuration roots, then add `--apply`
to update it. Include the affected Fish modules in `--components` if
applicable. The usual removal operation accepts either spelling.

Pending 0.3.0-1 migration journals recover with their original output hashes.
After recovery, explicit activation can refresh affected Fish blocks without
changing the migration ledger. New migration journals record the quoting rule
so retries reproduce the same file bytes. Recover new migration journals
before downgrading. To return an affected profile to 0.3.0-1, remove its
requoted blocks with 0.3.1-1 before downgrading.

Setup has no package hook. Activation, removal and recovery are explicit
ordinary-user operations. See the installed configuration migration and
repository enrollment guides for arguments and ownership.

## Local build

In a disposable checkout or recipe copy, run `makepkg --cleanbuild --nosign`.
Runtime dependencies are Python 3.11 or newer, GnuPG and pacman. The build
requires `patch`, and checks require a real Fish binary. The checks run the
original 29 migration cases against the patched modules and run staged
executables against temporary homes and templates from both versions.

On November 25, 2026, the x86_64 host build with
`makepkg --cleanbuild --nosign --noconfirm` passed all 35 checks, including six
real-shell and compatibility cases with Fish 4.9.3. Native ARM, installed
ALPM lifecycle and physical M2 qualification remain open.
