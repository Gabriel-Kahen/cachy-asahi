# Stored DNS profiles and saved sysctl experiments

The alternative [sysctl0.1.0-2 recipe](../../packages/tools/cachy-asahi-sysctl2/README.md) adds `cachy-asahi-sysctl experiments --state /absolute/private/store`. It lists saved names, baseline/target values and journal phases, while retaining incomplete or invalid entries. It does not read kernel values, create state, grant undo permission or automatically restore anything. Use explicit named `inspect` and `undo`; their existing boot, ownership and conflict checks still apply.

This is an alternative recipe for the same package name and installed command. Select one version; the original0.1.0-1 recipe remains available for its pinned native results. Native credit does not transfer between versions.

Twenty-eight local controls passed on Python3.12 and3.14, including the original19 mutation/conflict/interruption controls and9 read-only discovery controls. All writes use private model files. Actual package staging installed the five expected paths; the staged CLI read a plan created by the originalv1 program with saved bytes and model value unchanged. A saved journal is explicitly reported as `live_state: NOT_READ`.

[Native ARM paired builds and signed v1→v2 upgrade/removal/reinstall now pass](sysctl2-native-upgrade-20261018.md), including preservation and discovery of original private v1 records in two ordinary homes. Actual kernel restoration, M2 behavior and release selection remain NOT_RUN. This development variant is not selected by the supported-system inventory.

The alternative [DNS0.1.0-2 recipe](../../packages/tools/cachy-asahi-dns2/README.md) adds `cachy-asahi-dns profiles` and `cachy-asahi-dns --json profiles`. It lists stored UUIDs, types and display names using two bounded metadata queries. It does not request secrets/full profiles, write receipts, or modify/activate/reapply connections. Names are display data; UUID remains the explicit transaction selector. Malformed/multiline frames and changed identity sets refuse with an editor fallback.

Twenty-seven source and stage-loaded controls pass, including all21 original DNS transaction controls. The actual staged command passed against a genuine isolated x86 NetworkManager service with synthetic ordinary, escaped and Unicode names; stored fields were unchanged, and multiline names refused. Private daemon/actor/image cleanup passed. This uses a private test bus with PolicyKit disabled, not production authorization or effective DNS. Live DNS, production PolicyKit, Wi-Fi/VPN/M2 behavior and release selection remain NOT_RUN. The original0.1.0-1 recipe and its native evidence remain unchanged.
