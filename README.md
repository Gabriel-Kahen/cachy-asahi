# Bounded host BTF input diagnostic

This standalone read-only ARM64 job exports the running hosted kernel's original BTF and the complete C header generated by the host's root-owned native bpftool. It records exact source/run/job identity, kernel and host OS text, tool bytes/version, foreground command retirement, package/copyright observations, full output hashes and a 180-second bound. It installs nothing, creates no BPF program/map/namespace, and contacts no bus or network. Checkout and original artifact upload are the only transport actions.

The input is the exposed hosted kernel, whose version is not preselected. This is source-owned build-input DATA, not authenticated upstream kernel source, an Asahi/M2 kernel, a package build/test result, or kernel runtime portability proof. Kernel/header licensing and source provenance must be joined honestly before future reuse. The wrapper's MIT license does not license the kernel data. Missing native ELF bpftool or required host resources fails honestly while retaining partial bounded diagnostic DATA; no package installation, download, regular-file device substitute or parser fallback occurs.
