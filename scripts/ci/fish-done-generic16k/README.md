# Fish Done generic 16 KiB recorder trial

Separate manual diagnostic lane. Source implementation and inert controls do not
establish runtime success. Root owns integration, exact commit/workflow/manifest
freeze and actual CI. This worker runs no compiler, Docker container, VM, product
PTY driver, package installation or real notification actor.

The lane maps the twelve adopted `cachy-asahi-fish-done` 0.1.0-2 recipe sources and exactly
eight package payload files plus the existing eighteen-case driver. Every file has
an explicit source/destination/mode/byte/SHA256 binding, with upstream/project
licenses and notices retained. The guest reports
`NOT_INSTALLED_EXACT_SOURCE_PAYLOADS_COPIED_ONLY`; there is no pacman registration
or native package claim. Root's native package and installed lifecycle are separate.

The existing offline owned574 producer, six secret-seeded inputs and fourteen-file
public seed are reused unchanged. Its inventory SHA256 is
`cfd4c76f8602164c1091aed121332d201d0bf9299d3a51aedfb67f79c834e0ac`, including Fish
4.9.3-1. There is no new guest userspace/Rust/audio build or input download.

Read-only ordinary-user capture verifies inventory before/after, drops all
capabilities, requires no-new-privileges and no network, and imports definitions
only. It copies exact product/driver bytes, native Python sources/imported
extensions, Fish/resources, xterm terminfo and finite init/test tools including
sleep/sh/timeout/kill. Full ELF interpreter/DT_NEEDED closure is required; every
ELF must be AArch64 and structurally 16-KiB aligned. No real notify-send binary,
notification manager, desktop, D-Bus service or socket is copied. Limits are
4,096 files, 256 MiB total, 64 MiB/member, 270 MiB private tar, 1 MiB receipt,
240-second capture, 128 processes and 2 GiB memory.

After the marker/page guard, the guest drops supplementary groups and UID/GID to
23001. One bounded 240-second outer command runs the unchanged adopted driver
