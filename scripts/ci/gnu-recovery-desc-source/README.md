# GNU775 raw recovery descriptor source factory

This source-only successor extends the maintained GNU771 candidate-extraction
factory. It reproduces every file of public775
`8a6b9b7d5cb1def4ed95c2fd739d1354db292405` from an explicit ordinary export of
public771 `4b2f8502655d2f4b65a20691247d1a54052089f3`:
763 held,8 changed,4 added. All667 raw runtime files remain byte-identical.

```sh
python3 -I -B -Werror prepare.py \
  --parent /absolute/ordinary/4b2f-public771-export \
  --output /absolute/fresh/recovery-source --known-context
```

Omit `--known-context` for the default NULL context. Both contexts emit the
same775 bytes with file modes0644; only receipt `known_parent_context` differs.
The fixed parent/expected source identities describe reproduction inputs and
outputs. Current source/ref/run and Root acceptance stay NULL. There is no
binding, acquisition, native dispatch, installation or acceptance interface.

The hard-pinned profile contains complete before/after, held/delta and payload
maps. Three readable exact public Python payloads and plain JSON profile
operands are the complete addition. Counted edits and one explicit append
reproduce the selected worker loaders, required evidence profiles, workflow test
route and deploy footer. Deterministic manifest/workflow sealing joins the exact
target map before staging. `inverse()` reconstructs every771 parent byte,
including the counted loader append and previous seals.

Generation treats supplied source as DATA: it never imports, executes,
evaluates or compiles it. Runtime-profile hashes are pinned published DATA.
The factory bundles no whole historical source tree, compressed executable,
package archive, private configuration or key. Stable-FD reads, closed namespace
and directory identities, late complete source/payload/profile/entry rejoins,
canonical disjoint paths, fresh output, and staged byte/mode checks retain the
existing constructor controls, including same-byte inode-replacement refusal.

The emitted raw descriptor helper is byte-identical to the qualified public
source. Its parser normalizes only the single ASCII INSTALLDATE digit span;
every other byte and the file metadata remain binding. Duplicate or malformed
fields, reordered fields, non-ASCII/out-of-range dates, and changed REASON or
VALIDATION refuse. All573 unrelated package DB trees and the other held DB nodes
remain exact. The unchanged original exercises, process/checkpoint, payload,
configuration, security and cleanup predicates remain required. The normal
default route is unchanged. No DB acceptance rule is widened by maintenance.

Run both focused suites with ordinary independently pinned public fixtures:

```sh
export GNU_RECOVERY_PARENT=/absolute/ordinary/4b2f-public771-export
export GNU_RECOVERY_EXPECTED=/absolute/ordinary/8a6b-public775-export
python3 -I -B -Werror test_prepare.py
python3 -I -B -Werror test_source.py
```

Generation tests verify complete equality/inversion, known/NULL CLIs, mode0644
under restrictive umask, blocked source execution/process/network APIs and
hostile input/identity refusals. Separate source controls deliberately execute
only the verified emitted source: its complete775 entry and771/766/older gates,
both selected private667 derivatives and embedded helper pins, exhaustive
non-date byte/metadata binding checks, new raw descriptor fixtures and held
candidate/REMOVE synthetic controls. These do not perform a genuine libalpm
commit, native ARM recovery, VM or physical M2 test.

The companion read-only workflow exports the exact771/775 public revisions and
runs both suites on Python3.12/3.14. Hosted CI remains separate evidence.
Adoption paths are `scripts/ci/gnu-recovery-desc-source/` and
`.github/workflows/gnu-recovery-desc-source.yml`. Existing factories and frozen
authors are retained unchanged. Generic frozen-reader builder float comparisons
are outside this source-factory change.

Source reproduction establishes maintainability, not actual interruption
recovery, native fit, paired acceptance, physical FD reobservation,
binary/source correspondence, M2, power-loss, performance or release admission.
