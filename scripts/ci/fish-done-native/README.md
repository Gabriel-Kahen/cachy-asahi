# Native Fish Done candidate

Separate manual lane for the final12-source/eight-payload Done package,
version0.1.0-2. The frozen Tools and Autopair lanes remain unchanged. This
uses Autopair's small fixed-anchor adapter pattern around the exact pinned
Tools run/job code and the accepted Welcome build/preservation helpers.
It adds no general framework or dependency-fetch path.

The contract fixes original MIT source revision
`b86292a52a2b8f646ef8d25daa3cc01ccab60b62`, the unchanged complete upstream
record, complete upstream/project licenses, the reviewed Linux runtime,
wrapper and fixture bytes. The inert upstream conf.d record is installed
as done.upstream.fish, and is never sourced by the wrapper. No automatic
Fish startup or conf.d path is packaged.

The existing574 base already supplies Fish4.9.3-1, libnotify0.8.8-1,
coreutils9.12-2 and Python. Actual native daemon/image, complete inventory
and `pacman -T` dependency checks are required before the accepted Welcome
helper builds the package twice, offline in distinct clean read-only
containers. Generated SRCINFO, BUILDINFO recipe/source metadata, exact
payload hashes/modes/owners, license joins, PKGINFO, BUILDINFO, installed
trees and **whole archive bytes** must match. No ELF is allowed.

Actual ALPM lifecycle is574->575->575->574->575->574: install, same-version
reinstall, remove, reinstall-after-removal and final remove. Each installed
phase verifies all eight files and their ALPM ownership, then both fresh
and existing ordinary users run the product's exact eighteen-case driver
against the installed wrapper and adapted runtime. The complete original
inventory and guarded manual source behavior must return after removal.
Existing Fish config, conf.d preferences, universal variables, history,
symlink, system /etc/fish and generated user receipts remain protected.

All18 named cases and normal Fish exits are required: foreground
status/duration and exclusion gates; current-Fish single-process background
success, actual PROCESS_EXIT7 and SIGTERM143; pipeline/foreign watch and
disowned-job refusal; repeated source, caller continuation and preserved
hooks/custom binding; default privacy and literal/XML escaping; transport
failure and the2-second TERM plus1-second kill grace; disable and existing

these behaviors. Receipt gates additionally require the18 names, native
aarch64/Fish identity, installed wrapper/runtime hashes, raw receipt digest,
actual Fish executable hash and recorded page size.

**Notifications use a private notify-send process recorder only.** The
driver supplies a private PATH containing the exact498-byte recorder,
command symlinks and a deliberately unconnected private DBus address.
Recorder files must be ordinary-user-owned0700 scripts; JSONL output is
0600 and capped64KiB per case. No host notification bus or real desktop
notification is used or credited. Raw argv/PID transcripts and their byte
digests are retained in lifecycle proof and joined to the reported status,
privacy and escaping cases. The timeout recorder PID must be absent;
repeat hooks, custom binding and source-caller continuation are checked
from their actual fixture files. No erased user edits are allowed.

Four owned consumers are required: probe, two builds and lifecycle.
Persist-before-launch names, exclusive lease, actual ID/image/name/label
checks, foreign/unknown refusal, confirmed-ID removal and absence checks
remain unchanged from the accepted helper. Only after all consumers retire
can the original owned574 producer be removed. Partial execution cannot
earn candidate acceptance.

The workflow has its own `native-arm-fish-done-candidate` concurrency group
and cancellation disabled. Source must equal workflow revision before the
existing six-file secret seed and14-file public checkout route. One closed
96MiB export retains both exact archives, source/licenses, harness, build
metadata/logs, complete local recorder lifecycle proof and ordered cleanup.
It includes hidden files only in that bounded public directory; export
enumerates frozen harness and exact recipe inputs, preserving .SRCINFO and
excluding arbitrary hidden files, HOME, caches and container layers.
