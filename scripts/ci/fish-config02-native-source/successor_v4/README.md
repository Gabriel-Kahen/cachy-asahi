## New explicit contract

- The recipe pins literal `PKGEXT='.pkg.tar.xz'`. Only its reviewed PKGBUILD hash
  and corresponding explicit profile/closure pins change. Fish config, checker,
  .SRCINFO, notices/licenses and dependency metadata remain exact.
- The active builder and comparison projection require exactly
  `cachy-asahi-fish-config-0.1.0-2-any.pkg.tar.xz`, an ordinary non-symlink file
  and actual XZ magic before archive inspection. The comparator gate precedes
  evidence digest reads as well. Other names/formats and special files refuse.
- The finisher retains every semantic/provenance/distinct-environment/equality
  guard and adds the exact archive name and actual XZ header checks.
- The host catalogue contains only the existing twelve required tools. The
  bsdtar predicate and APT/dpkg catalogue, module, runner, cache and declaration
  are removed together. The policy explicitly admits zero package-manager
  invocations and zero host package mutations; it requires stdlib XZ inspection.
- All fifteen public native CI/platform checks remain, with only the new Source
  ref namespace adapted. Context is persisted before tool preflight. All twelve
  tools must already be valid; there is no acquisition or fallback installer.
- Fresh Root documents must use `ROOT_FISH02_NO_HOST_APT_ADMISSION_V4` and
  `ROOT_FISH02_NO_HOST_APT_RUNTIME_V4`, the exact new Source/program/policy and
  host-tools declaration. Old APT admissions and receipts cannot satisfy it.

Signed349 inputs/rootfs, detached signatures, GPG validation, bootstrap package
