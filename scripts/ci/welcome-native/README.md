successful exact574 builder handoff and immutable linux/arm64 image. It probes

There is no --nocheck, --skipchecksums, dependency installation or network fetch.
The effective makepkg/pacman configuration, exact lock, generated metadata and
complete bounded build log remain evidence. Retained config declares !debug,
!lto, check and .pkg.tar.xz; actual output/config is inspected rather than assumed.
