Additive successor to `doctor2-comparison-native-source`. That constructor and
`doctor2-native-source` remain frozen. This constructor accepts the exact current
Doctor2 0.2.0-2 nine-input recipe and genuine original705 source62. It emits a
closed70 source with retained574 transport, rather than treating the older63

The selected map is byte-identical to the separately published source
`88997143a593f2de82fb41ae0224a943a1f99930`, reference
`codex/doctor2-retained574-isolated-entry-v2`. These identify approved input
bytes, not this constructor's publication or a native result. Its own actual

No runtime observation or acceptance is manufactured.

```sh
python3 -I -B scripts/ci/doctor2-current70-native-source/prepare.py \
  --current-root /absolute/current-checkout \
  --native-root /absolute/exact-705-source62 \
  --historical-factory-root /absolute/current-checkout/scripts/ci/doctor2-native-source \
  --comparison-factory-root /absolute/current-checkout/scripts/ci/doctor2-comparison-native-source \
  --output /absolute/fresh-source70
```

are NULL. It refuses source proof before proof/job output. `--selected` binds
only the current nine-input recipe/version; it still supplies no actual selectors
or acceptance. A future real run needs Root's genuine source publication and
all unchanged source/workflow/ARM/secret/producer/runtime gates.

`--historical` omits `--current-root` and delegates to the whole-pinned unchanged
original705 constructor with its genuine62 source for both historical operands.
