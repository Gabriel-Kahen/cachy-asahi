Source map, constructor profile, policy and Reader program. Publication is the
only known operational identity. Its actual v2 run/job, Original, package,

The constructor reads the complete canonical LLVM251 Source and the exact
Rust279 Source as DATA. It verifies every byte, mode, membership, total, Git tree
and Source map. It retains only the small policy, contract, candidate-map and
Reader program snapshots needed by the new gate. The archived Reader is never
imported or invoked by this constructor or the tests. The existing 277- and
279-file constructors, profiles and outputs remain unchanged. A complete inverse
restores Rust279 before its own inverse restores Rust277.

A new wrapper preserves the complete previous Rust qualification gate as a

`llvm.policy` contains its byte/hash pin and full `resources` object. `llvm.reader`
