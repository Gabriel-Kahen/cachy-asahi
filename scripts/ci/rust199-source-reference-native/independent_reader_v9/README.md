## Bounded API

Copy `request.TEMPLATE.json` outside this Reader tree. Root must select the exact
source commit/ref, first run/distinct bootstrap+build jobs, three current Original
artifacts, whole dispatch/review/publication bodies, observed v8 storage host and
needs pins. It must explicitly admit the proposed Reader resources and complete
retained-file ledger, then set issuer/approved. The checked-in template refuses.
Root independently pins this six-program Reader closure before launching; the
request also binds those six whole files. No helper invents operational authority.

```
python3 -I -B scripts/ci/rust199-source-reference-native/independent_reader_v9/reader.py \
  --request /absolute/Root-selected-request.json --request-sha256 WHOLE_SHA256 \
  --source-root /absolute/files-only-Source333 \
  --evidence-root /absolute/closed-retained-ledger \
  --scratch /absolute/fresh-owned-0700-directory --output /absolute/fresh-result.json
```

`files` maps safe relative ledger names to exact `{bytes,sha256}` descriptors.
`roles` has exactly the keys in the template; every value names a ledger file.
`external_files` optionally maps ledger names to explicit absolute retained public
file paths, avoiding copies of large already-retained archives. Only Root-selected
ledger paths are opened. Producer paths are never followed. The evidence-root
namespace must equal all non-external ledger files, without aliases, hardlinks,
special nodes, empty extra directories or unlisted contents. JSON duplicates and
nonfinite values refuse. Stability includes device/inode/mode/link/owner/size/
mtime/ctime; read-updated atime is excluded. Whole retained data is capped at48GiB.
The resource proposal is exactly600s wall/CPU,1GiB virtual AS,4GiB scratch and at
most8 scratch files. Only the two internal temporary spools are used concurrently.
The CLI sets its own core/AS/CPU/file limits only after explicit Root DATA
selection; unissued requests refuse before those syscalls or evidence reads.

`members.bootstrap`, `members.build` and `members.transfer` map **every actual
Original ZIP file member** to its ledger name. Directory entries may only be
ancestors. Unknown files, alternate member bodies and changed archives refuse.
Bootstrap/build operation captures use ledger names
`bootstrap/operations/NNN.stdout` (or stderr) and `build/operations/NNN.stdout`.
Their ZIP member keys are `operations/NNN.stdout`/stderr. Other ledger names are
Root-selected; the artifact member names must be read from the actual archive,
not guessed from a future artifact. Source metadata paths remain DATA.

The three top-level Originals are externally selected as separate bootstrap
observations, build observations, and qualified-image transfer. The generic
workflow is381664314, `.github/workflows/native-arm-build.yml`; selected Source
workflow body is separately Source-bound. Registration on Main does not imply
that Main contains the selected Source body.
