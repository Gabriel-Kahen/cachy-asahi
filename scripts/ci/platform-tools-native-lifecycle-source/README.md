# Platform tools native lifecycle Source constructor

This original MIT, Source-only helper reconstructs a separate exact native
candidate from the retained genuine191 parent plus a finite pinned13-leaf
payload. It never builds, signs, installs, downloads, starts a VM/container,
opens an evidence capsule, mutates Git/API state or dispatches a run.

Canonical adoption targets `main`, with base
`3a3ccc6c69d1b800dc47fbaea051b87f5f3d43b4`. The native candidate itself retains
genuine sole parent `111f14d2b21b220d86912d5ead978848c7ef1cb0` and the corrected
immutable source/cache/process framework. These two parents serve different
purposes: the first is the project PR base, the second is the native Source
lineage. No host package recipe or shared manifest is changed here.

```sh
mkdir -m700 /absolute/private-source-output
python3 -I -B scripts/ci/platform-tools-native-lifecycle-source/prepare.py \
  --basis /absolute/retained-genuine191-source \
  --output /absolute/private-source-output/platform-trial
```

The caller supplies the locally retained parent bytes; the helper will not
fetch missing inputs. `profile.json` binds every191 basis leaf, every13 changed
payload leaf, every199 result leaf, modes, parent raw commit and complete source
map/tree hashes. The fixed profile hash is compiled into `prepare.py`. The
parent raw commit is included only to prove the genuine tree/commit join.

Output contains the complete199-file `source/`, source authorization and modes,
prospective Git blobs, the15-path delta and original seven before-operands,
raw parent commit and Source-only stage metadata. Publication/run/job/artifact
actuals remain NULL. The original200-row source cap,1154 retained DATA profile,
400/480-second transport clocks and owned-process/runtime contracts are held.
A new output is published without replacing a concurrently created destination.
All Python is compiled in memory; no candidate module is executed or cached.

makepkg builds with ordered25+15+9 passing checks each, exact package and
