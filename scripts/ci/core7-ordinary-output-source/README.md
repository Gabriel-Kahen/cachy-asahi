# Core45 ordinary pacman output source factory

This separate source-only constructor reproduces all45 files of public
`8592e58faaea5a9ab59db625952286b79d96f0f1` from all44 files of public
`15a41fda11ac9ffa0ae4a7a53697d5f63a913a57`. Supply ordinary exported source
trees; Git checkout metadata is outside the closed input namespace.

```sh
python3 -I -B -Werror scripts/ci/core7-ordinary-output-source/prepare.py \
  --source /absolute/public44 --output /absolute/fresh45 --context known
```

`--context null` emits identical source bytes with NULL receipt identity. Both
contexts leave actual/native acceptance unset. The only runtime change removes
the redundant pacman `--debug` argument. Normal hook logs, witnesses, archive
signatures, complete graphs and accounts, retirement, all90s/1MiB transaction
limits and enclosing clocks remain held. The readable guard reconstructs the
whole44 ancestor and executes its complete source predicates.39 leaves are
unchanged; source-entry/manifest/workflow seals follow the change.

The factory performs no Git/API, package, VM, signing or system operation. It
authenticates the complete source/profile/payload, checks fresh disjoint paths
and rechecks inputs before writing. It does not grant acceptance or establish
that the native transaction fits90s. M2 and release remain unqualified.

Portable controls take explicit fixtures:

```sh
CORE_ORDINARY_INPUT=/absolute/public44 CORE_ORDINARY_EXPECTED=/absolute/public45 \
  python3 -I -B -Werror scripts/ci/core7-ordinary-output-source/test_source.py
```

They compare both real CLI outputs against every public45 file, execute the
whole emitted source entry, reconstruct the entire44 ancestor, and refuse
drift/missing/foreign/link/path inputs before output. Existing Core factories,
routes and defaults are unchanged.
