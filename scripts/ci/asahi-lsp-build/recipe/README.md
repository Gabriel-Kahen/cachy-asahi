# Private headless LSP native build proposal

**Source prepared; all build/package/native execution NOT RUN.** This recipe is for the existing `scripts/build/build.py` and `scripts/build/compare.py`, unchanged. The standard builder and checks are unchanged; no platform exception is introduced. The coordinator owns image/input selection, two fresh builds and later publication decisions.

Before static recipe review, copy this recipe to a fresh private directory, place the already retained `lsp-plugins-src-1.2.35.tar.gz` there, and verify its SHA256 against `PKGBUILD`/`.SRCINFO`. Keep that archive out of Git and public artifacts. It is a local offline input; do not run `make fetch`, `tree` or `distsrc`. Freeze the resulting ordinary static recipe `input_sha256` object and full immutable builder inventory using the existing process. The helper digest is also pinned. No source archive or generated binary is publicly exported by this proposal.

Use a network-none native aarch64 image containing Make, GCC/G++, binutils, coreutils timeout/install, pkgconf, Cairo/libsndfile headers and their actual dependencies. Existing 574/587 metadata is not proof that a selected image supplies them. `build.py` already provides a fresh nonroot container, fixed image/inventory, capability/memory/process/time limits and package metadata/ELF checks. Set its overall timeout to at least the reviewed 1800-second make limit plus configuration, staging and cleanup; do not use an emulated build as native acceptance.

`build()` invokes the local helper inside that container. It checks native identity/tools, probes Cairo/libsndfile and C/C++ headers, then configures **FEATURES=lv2**, Armv8-A/generic, no LTO, with two make jobs. Inherited CFLAGS/CXXFLAGS/LDFLAGS are removed only for configuration so upstream supplies its audited common flags; retain the resulting `.config.mk` and full build log. Upstream metadata generation/validation executes as part of the build. Compiler versions, effective configuration, shared-object readelf output and hashes are printed into the standard retained build log. The helper's private scratch evidence is not a separate export mechanism.

`package()` uses makepkg's ephemeral `pkgdir`; it never installs onto the host. It copies only the DSP shared object into `usr/lib/lv2/lsp-plugins.lv2/`, runs the source-built TTL generator, and stages root GPL/LGPL texts, LV2 copying text, the complete Ardour inline-display notice/header and an explicit source/version notice. Notice basenames are `COPYING`, `COPYING.LESSER`, `LV2-COPYING`, `Ardour-inline-display-NOTICE`, `SOURCE-NOTICE`. The inspected TTL generator treats `-i` as a filename for emitted references and enumerates metadata linked into the generator (`lv2ttl_gen.cpp:250-251,1303-1321`); it does not dynamically load the produced plugin in that path. This is build-time tool execution; it does not instantiate a DSP/audio graph or establish plugin-host correctness. No `make install`, service, PipeWire graph, audio device, UI, speaker playback or hardware setting is invoked.

The private package name has no `provides`, `replaces`, `conflicts` or protected-platform exception. The LV2 bundle path and URIs overlap upstream's plugin identity: **do not co-install it with another LSP LV2 package**. Installation, host discovery, required Asahi URI/control ports, actual ELF runtime closure and 16 KiB/M2 execution remain separate untested work. The minimal license set is a source-derived proposal; notice/source/relinking delivery and the final binary closure need review before redistribution.

For the coordinator's bounded log projection, fixed `LSP_STAGE` markers cover `prereqs`, `config`, `build`, `ttl`, `package`; fixed `LSP_PROBE` markers cover `compiler`, `pkgconf`, `cairo`, `sndfile`, `headers`. START/PASS and failure-trap FAIL markers are diagnostic progress only. Raw compiler/config text remains in the standard private build log; the caller can select only those fixed markers for sanitized failure output.

After configuration, the helper parses data without sourcing/evaluating it and emits `LSP_CONFIG` for exactly `BUILD_FEATURES`, `CFLAGS`, `CXXFLAGS`, `HOST_CFLAGS`, `HOST_CXXFLAGS`, `SO_FLAGS`, `HOST_SO_FLAGS`. Missing/duplicate/oversized fields fail. Features must normalize to exactly `lv2`; all four compiler fields must contain Armv8-A/generic tokens. All selected flag fields reject LTO, CPU selection and conflicting architecture/tuning tokens. Each selected value is limited to 2048 characters; the complete generated configuration stays private.

The coordinator should run the existing native builder twice with the same source epoch/image/input lock, then the existing comparison CLI. The standard package checker supplies structural ELF/16 KiB observations; readelf structure never counts as physical 16 KiB execution. No image pin, actual input lock, passing build, byte reproduction, plugin processing, audio safety or performance result is asserted here.
