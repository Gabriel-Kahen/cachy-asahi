# Finite runtime54 namespace admission overlay

This is a DATA composer and an externally Root-bound adapter for **fresh**
namespace diagnostic packets. It does not enter preflight, Native, Original or
Reader roles, open/acquire the shared lock, issue resource authority, install
anything, or change an old packet. Root owns every actual role.

The original preparation composer is pinned to commit
`5e23a55670d84162f03f7e0586917411bdb6cf06` in the separate preparation checkout.
`composer-inputs.json` binds all 28 committed operands and its parent raw commit.
The composer revalidates its original Source200, complete external closure and
optional genuine PR433 factory binding. It reads no consumed role outputs.
The original `ready-pr433-r2/Root-preflight-000` is consumed permanently: its
failure DATA says HOLD at `same existing shared lock FD/path identity`, zero
Native POSTs, Original GETs and Reader calls, CLOSE_ONLY. Never reuse that index.

## Root profile and fresh composition

The default `Root-runtime54-profile.TEMPLATE.json` has NULL approval/time and
`ROOT_MUST_ATTEST_EXACT_EXISTING_LOCK_RUNTIME54` status. The composer never
issues it. A fresh default packet has a NULL external profile reference and
refuses in `verify_packet` before bootstrap, lock open or role output. Root
must independently attest the **complete literal identity** in a canonical
external ordinary single-link JSON file, with these three changed fields:

```json
{
  "status": "ROOT_BOUND_EXACT_EXISTING_LOCK_RUNTIME54",
  "approved": true,
  "attested_at": "<Root's actual timezone-aware ISO timestamp>"
}
```

All other fields must match the template exactly. This is an identity
attestation only: `resource_authority` and `lock_mutation` must remain false.
The attestation must be at most3600s old and never future-dated. Its canonical
external path and whole bytes/SHA256 enter both local binding DATA and the
complete input seal. Whole profile, schema, pin, freshness and full real FD/path
identity are rechecked on every identity call. Every such call also checks the
reference against its original sealed input-index pin, so coordinated reference
and profile replacement cannot renew the attestation. No supplied identity is learned
from a stat result. Profile changes, aliases, hardlinks, partial/extra fields,
old devices, changed inode/owner/mode/time or stale/unissued approval refuse.

Validate retained DATA with no writes:

```sh
python3 -I -B scripts/ci/native-lock-runtime54/prepare.py
```

Future Root composition supplies both independent bindings and a new absolute
owned safe output directory. These are DATA composition arguments, not role
entry arguments:

```sh
python3 -I -B scripts/ci/native-lock-runtime54/prepare.py \
  --factory-binding /absolute/Root-factory-binding.ACTUAL.json \
  --factory-binding-sha256 WHOLE_FACTORY_BINDING_SHA256 \
  --root-runtime-profile /absolute/Root-runtime54-profile.ACTUAL.json \
  --root-runtime-profile-sha256 WHOLE_PROFILE_SHA256 \
  --output /absolute/owned-safe-parent/FRESH-packet
```

Existing or partial directories refuse and are preserved. Never amend an
unissued or consumed packet to issue its profile: compose another fresh packet.
Root's separate resource reviews, fresh zero-active/zero-pending exclusive
HEAVY_NON_KERNEL/native-arm-build reservation, clean current Main CAS,
independent source/live preflight and actual POST authority remain required.
The profile grants none of them. Future Original intake still requires its own
Root authority; this change does not execute or grant an intake/Reader route.

changed. Python3.12 was not run for this overlay.
