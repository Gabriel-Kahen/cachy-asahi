finite whole-pinned v3 construction closure and uses its strict original basis,
carrier, recipe, trust-proof and inventory checks. It executes no owner, route,
executor, Reader, package, GPG, network or lease operation. No new actual Source

`assemble(repo, closure_raw, carrier_raw, manifest_raw)` requires one full actual
