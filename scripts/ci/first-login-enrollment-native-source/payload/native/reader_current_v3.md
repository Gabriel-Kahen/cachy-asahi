# Independent public current-stage Reader v3

`reader_current_v3.py` replays the public format from `retention_current_v3.py`. It imports no producer or Source code and follows no paths from the evidence. It invokes no decoder command, package code, GPG, Docker, network, lease or actor. Old Reader and source139 are unchanged.

The entry point consumes bytes and externally selected pins:

```python
verdict = reader.read_stage(
    capsule_bytes, expected=external_binding,
    source_files=closed_source_bytes, support_files=public_support_bytes,
    now=reader_utc_unix_time,
)
```

A complete replay returns `PASS_PUBLIC_CURRENT_STAGE_DATA_ONLY`. Missing, malformed, provisional, stale, wrong-tuple or uncertain evidence returns `HOLD` with reason codes. Every verdict keeps `Root_authentication:false` and Root/component/hardware/release acceptance null. Successful DATA replay is not a Root grant, native compatibility or hardware/release acceptance. No actual production Source/job/runtime/admission binding is emitted here; those remain unissued until Root supplies genuine qualified observations.
