# Conventional GNU provider: standard system paths on generic16K

Runnable separate source/CI proposal; input-policy.json is intentionally UNBOUND.
No package bytes, provider digest, native run ID or future accepted input ref is
invented. Root binds the actual glibc-gnu-provider-packet/prepare.py packet only
after accepting the NEW conventional native pair and normal probe outputs.
No compiler, candidate, container, VM, network or host system actor was run by
this worker. Existing private-prefix16K, provider build/lifecycle and Asahi policy
are unchanged.

This lane supplies distinct system-path runtime evidence, labelled everywhere
`DATA_STAGED_PRIVATE_ROOT_NOT_ALPM_INSTALLATION`. Accepted candidate runtime/data
are staged at conventional /usr/lib, /usr/lib/gconv, /usr/lib/locale and /usr/bin
inside a private /system chroot in a diskless generic16K VM. /lib→usr/lib supplies
the normal interpreter alias. Full ALPM replacement/reinstall/held restoration
belongs to glibc-gnu-provider-lifecycle; this trial claims none of it.

## Actual accepted inputs, never a rebuild

The packet is consumed directly: packet.json/files, archives a/b, provider_pair,
held, probes and probe_receipt. The normal decision's compile_receipts a/b bind
the original runtime/{a,b}/normal-clients/receipt.json. Every declared reference
and complete index.files map is rehashed. Pair acceptance, exact byte equality,
conventional PKGINFO/provides/conflicts/dependencies/backup, BUILDINFO recipe,
absence of candidate scriptlets/hooks, normal probe acceptance and all normal
compiler/source/header/patch/ELF records remain required. The unchanged provider
normal_clients.validate checks both original13-command receipts against the three
actual probe files; only its data-file lookup is mapped to those bound references.
No accepted receipt is relabelled a current compilation or16K execution.

No new glibc or test-client build occurs. The one ordinary read-only/no-capabilities
owned574 capture compiles only the unchanged freestanding static page probe.
It captures the accepted precompiled smoke-normal, direct exec-child and plugin;
the conventional provider runtime subset; held bootstrap Python/core ELF and
complete same-root dependency closure; and the exact held rollback archive.
Candidate gconv helper lookup stays within that root, including $ORIGIN helpers.
Bootstrap lookup stays outside it. Missing/foreign/4K ELF fails. Source/roles/
program identities and every captured byte/mode are rechecked at the receiver.

The complete held574 inventory must match before/after capture. Outer held loader,
libc and libm must match the unchanged rollback archive bytes. Those outer roles
remain active at guest /usr/lib and are checked again after trial; the original
archive stays accessible under /recovery and in the untouched input packet.
Only private target data are staged, never the host or borrowed provider.

## Actual16K normal-interpreter flow

The held bootstrap mounts private /system proc/dev, checks uname/getconf and the
unchanged mmap/mprotect/file-offset page probe, then runs a root-only VM-marked
Python launcher. That launcher chroots, clears supplementary groups, sets UID/GID
23001, checks the resulting IDs and directly execve's the normal program. It
never invokes a candidate loader explicitly. Its fixed environment contains no
LD_* override, GCONV_PATH or LOCPATH. An actual pre-exec identity file supplies
UID/GID/group evidence. Captured normal programs have standard PT_INTERP, and
smoke-normal's sole accepted source edit makes exec-child a direct exec too.

Three supervised guest commands are required: standard locale -a with C.utf8,
standard ISO-8859-1→UTF-8 iconv, then smoke-normal's eight parent cases plus the
exec child. The lifecycle owner's role_identities/validate_runtime functions
are reused with exactly one semantic change: expected page4096→16384. Their
normal executable, actual device/inode/hash, loader/libc/libm/symbol, plugin,
gconv, locale and12-record requirements remain intact. Host receipt checks also
require all standard path groups/cases and reject explicit/private loader maps.
No captured inode number is transplanted into guest evidence.

Complete captured payload/held roles remain byte/mode unchanged. All UID23001
processes and each command group must retire. The original normal compile data
are recorded separately, not counted among the three current guest commands.
Only actual kernel/probe/runtime16K results earn runtime credit; ELF alignment
or a glibc version string alone cannot pass.

The new controller uses the canonical private16K trial's finite owner/retire/
cleanup-safe/finalize machinery. Fixed adapters change only marker/label/scope,
input provenance and the explicit private-root mount/cpio entries; system-specific
