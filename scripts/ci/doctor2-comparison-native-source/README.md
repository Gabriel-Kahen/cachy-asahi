# Maintained Doctor2 comparison source constructor

Additive source-only successor. Complete genuine70562 remains the mandatory
predecessor, and the original `doctor2-native-source` constructor remains unchanged.
The new constructor requires the exact maintained Doctor0.2.0-2 nine-input recipe,
including `test_comparison.py`, and emits a completely pinned63-file context.
It never imports mutable canonical package files into historical emission.

Required explicit operands:

```sh
python -B scripts/ci/doctor2-comparison-native-source/prepare.py \
  --current-root /absolute/current-checkout \
  --native-root /absolute/exact-705-checkout \
  --historical-factory-root /absolute/current-checkout/scripts/ci/doctor2-native-source \
  --output /absolute/fresh-comparison63
```

Default emission is UNBOUND: recipe/version/input selection and actual source/ref/
run are NULL. Native source proof refuses before producing proof or job output.
Explicit `--selected` binds only the exact new recipe/version/nine inputs; actual
source/ref/run remain NULL. This is a future native-build source context, not a
native result, acceptance or publication. An actual future run needs Root's
separate exact source/workflow revision and unchanged proof/runner/security gates.

`--historical` omits `--current-root` and invokes the original unchanged constructor
with the verified exact705 tree as both its historical current and native operands.
It reproduces exact62 default or (`--selected`) selected views with all old8-input,
whole-source and policy checks intact. The explicit view label prevents old0.2.0-1
native evidence being mistaken for coverage of new0.2.0-2 code. The old default
constructor can also still be tested directly against that exact historical tree.

The successor changes only the five package operands and nine context leaves:
contract version/count/log gates, caller archive identity, corresponding source
fixtures, policy, source-pins43, manifest60 and two workflow hash operands. All19
old native-source tests and8 caller tests remain, with one new strict16/11/20
complete-log inverse test. The runner/lifecycle/archive handlers, shared builder,
protected payload checks, cleanup, secret access, offline/nonroot constraints,
workflow topology and time/memory/output budgets remain unchanged. Both workflow
aliases differ from the old source only in caller/manifest checksum operands.

The profile is whole-file pinned by `prepare.py`. It pins the original constructor,
new nine-file package, exact generated bodies, full63 default/selected maps and
unchanged actors. Both inputs and planned output are checked before output creation;
source file reads reject aliases, hardlinks, special files and observed changes.
An I/O failure during emission can leave a partial new directory; final whole-tree
verification is required and a failed emission is never usable source evidence.

Focused constructor controls:

```sh
DOCTOR2_COMPARISON_CURRENT_SOURCE=/absolute/current-checkout \
DOCTOR2_NATIVE_SOURCE=/absolute/exact-705-checkout \
DOCTOR2_HISTORICAL_FACTORY=/absolute/current-checkout/scripts/ci/doctor2-native-source \
python -B -Werror::ResourceWarning -m unittest discover \
  -s scripts/ci/doctor2-comparison-native-source -p test_prepare.py
```

Run emitted `scripts/ci/welcome-native/test_native.py` and `ci/test_caller.py` using
separate unittest discovery processes, and the emitted Doctor2 three package test
scripts. The generic `contract`/`caller` module names must not be shared between
historical and successor contexts in one Python process. Tests simulate native
metadata only; they do not start a native actor, sign/install a package or establish
live audio/GUI/16K/M2/performance/release acceptance.

The separate current606353/real27361 constructors intentionally emit their exact
older Doctor2 sources. They and their old proofs/inverses are frozen; this factory
neither rewrites them nor transfers their results. The unused Doctor1 seven-input
compatibility context inside705 remains exact historical material as well.
